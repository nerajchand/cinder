# Workshop docs

Cinder was built by a coordinator agent that planned the work, sent tasks to subagents in separate git worktrees, and reported back to a human. These docs turn that exercise into something other people can repeat: a record of what happened (including what went wrong), a 90-minute workshop plan, and a step-by-step process.

- [timeline.md](timeline.md): what the user asked, what was delegated, what landed in the repo, what went wrong, and what is unverified.
- [workshop-plan.md](workshop-plan.md): a 90-minute workshop with prerequisites, a minute-by-minute run sheet, an exercise, facilitator notes, failure modes and a repeatable-run checklist.
- [playbook.md](playbook.md): the repeatable process, with an `AGENTS.md` template, a delegation prompt template, a verification checklist, a merge procedure, and how to run it again for a different app idea.
